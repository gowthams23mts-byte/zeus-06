# Gowtham S. Portfolio

A modern, responsive portfolio website built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide React.

## Features
- Responsive portfolio layout for desktop, tablet, and mobile
- Dark/light mode toggle
- Smooth animations and section transitions
- Project cards with filtering
- Resume download link
- Contact section with placeholders for personal links

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started
1. Install dependencies
   `ash
   npm install
   `
2. Run the development server
   `ash
   npm run dev
   `
3. Build for production
   `ash
   npm run build
   `

## Project Structure
- src/ contains the page sections, components, and content data
- public/ contains static assets such as the resume PDF

## Deployment
This project is ready to be deployed to Vercel or any static hosting platform.

## Contact
Replace the placeholder contact details in src/data/content.ts with your real links before publishing.
