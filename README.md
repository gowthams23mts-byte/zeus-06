# Gowtham S. Portfolio

A modern, responsive personal portfolio website built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide React. It showcases the academic background, technical skills, engineering projects, industrial experience, achievements, certifications, and a downloadable resume in a clean, recruiter-friendly layout.

## About Me
Gowtham S. is a final-year B.E. Mechatronics Engineering student at Kongu Engineering College with interests in robotics, industrial automation, PLC programming, embedded systems, automotive engineering, PCB design, home automation, and sustainable engineering.

## Features
- Responsive layout for desktop, tablet, and mobile devices
- Modern dark/light theme toggle
- Smooth animations and polished UI transitions
- Project cards with category-based filtering
- Downloadable resume section
- Contact placeholders for professional links and communication
- Accessible structure and semantic sections

## Technologies Used
- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Folder Structure
- `src/` — application components, sections, and portfolio content
- `src/components/` — reusable UI building blocks
- `src/data/` — portfolio content and project data
- `public/` — static assets such as the resume PDF

## Installation
```bash
npm install
```

## Running Locally
```bash
npm run dev
```

## Build Instructions
```bash
npm run build
```

## Deployment
This project is ready to be deployed on Vercel or any static hosting platform that supports Vite applications.

## Contact
Replace the placeholder contact details in `src/data/content.ts` with your real email, phone number, LinkedIn, GitHub, and location information before publishing.
